# 📘 Django Rest Framework 📘

## 1. Installation 📄

#### Requeriments

python3.10

#### Create virtual environment

```bash
python3.10 -m venv venv

source venv/bin/activate
```

#### Install from requirements.txt

```bash
pip install -r requeriments.txt
```

---

## 2. Run the project 💻

```bash
python manage.py runserver
```
